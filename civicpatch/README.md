# civicpatch

## Development

### Requirements

* [environment setup](#environment-setup)
* [mise](https://mise.jdx.dev/getting-started.html)
* [docker](https://www.docker.com/products/docker-desktop/)

### Commands

#### Run tests

* `mise unit`
* `mise integration`

## Environment Setup

Add a .env file with the following variables:

```dotenv
GOOGLE_GEMINI_TOKEN=
OPENAI_TOKEN=
BRAVE_SEARCH_TOKEN=
GOOGLE_SEARCH_TOKEN=
SERP_SEARCH_TOKEN=
```
